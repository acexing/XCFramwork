## 1. 模块职责

- `open` / `close` / `closeAll` / `get` 统一UI入口
- 支持全屏页面、普通弹窗、提示、加载界面等类型
- 维护 UI 层级：背景层、页面层、弹窗层、提示层、系统层
- 防止同一弹窗重复打开；支持参数传入和关闭回调
- 页面关闭时注销事件、停止动画、释放临时引用
- 统一处理分辨率适配、安全区域、键盘/返回键行为

## 2. 接口定义

```typescript
export interface IUIManager {
  open<T extends BaseView>(viewId: string, data?: unknown, options?: UIOpenOptions): Promise<T>;
  close(viewId: string): void;
  closeAll(excludeSystem?: boolean): void;
  get<T extends BaseView>(viewId: string): T | null;
  isOpen(viewId: string): boolean;
  showLoading(text?: string): void;
  hideLoading(): void;
  showToast(text: string, duration?: number): void;
}

export interface UIOpenOptions {
  type?: UIType;           // UI类型
  priority?: number;       // 层级优先级（同层内排序）
  exclusive?: boolean;     // 是否互斥（打开时关闭同层其他）
  cache?: boolean;         // 关闭后是否缓存（不销毁节点）
}

export enum UIType {
  FullScreen = 0,  // 全屏页面
  Dialog = 1,      // 普通弹窗
  Toast = 2,       // 提示消息
  Loading = 3,     // 加载界面
  System = 4,      // 系统级（错误提示等）
}
```

## 3. 类结构设计

```
UIManager
├── private layers: Map<UIType, UILayer>       ← 各层级容器
├── private views: Map<string, ViewRecord>     ← 已打开的视图记录
├── private viewCache: Map<string, Node>       ← 缓存的视图节点
├── private root: Node                         ← UI根节点
│
├── open<T>(viewId, data?, options?): Promise<T>
├── close(viewId): void
├── closeAll(excludeSystem?): void
├── get<T>(viewId): T | null
├── isOpen(viewId): boolean
├── showLoading(text?): void
├── hideLoading(): void
├── showToast(text, duration?): void
│
├── private createLayer(type): UILayer         ← 创建层级容器
├── private loadViewPrefab(viewId): Promise<Prefab>
├── private instantiateView(prefab, data): BaseView
├── private onResize(): void                   ← 分辨率适配
└── private onBackKey(): boolean               ← 返回键处理
```

**ViewRecord 结构：**
```typescript
interface ViewRecord {
  viewId: string;
  node: Node;
  view: BaseView;
  type: UIType;
  options: UIOpenOptions;
  openTime: number;
}
```

**UILayer 结构：**
```typescript
interface UILayer {
  type: UIType;
  container: Node;      // 层级容器节点
  children: ViewRecord[]; // 该层当前打开的视图列表
}
```

## 4. UI层级设计

```
UI Root Node
├── BackgroundLayer (zIndex: 0)   ← 背景层：全屏页面背景
├── PageLayer (zIndex: 10)        ← 页面层：全屏页面
├── DialogLayer (zIndex: 20)      ← 弹窗层：普通弹窗
├── ToastLayer (zIndex: 30)       ← 提示层：Toast消息
├── LoadingLayer (zIndex: 40)     ← 加载层：加载遮罩
└── SystemLayer (zIndex: 50)      ← 系统层：错误提示、系统弹窗
```

**层级规则：**
- 高层级始终显示在低层级之上
- 同层内通过 priority 排序
- `exclusive` 选项：打开新视图时关闭同层其他视图
- System 层不受 `closeAll` 影响（除非 `excludeSystem=false`）

## 5. BaseView 生命周期

```typescript
export abstract class BaseView extends Component {
  protected viewId: string;
  protected viewData: unknown;

  // 生命周期方法
  protected onOpen(data?: unknown): void | Promise<void> {}  // 打开时调用
  protected onShow(): void {}                                 // 从隐藏恢复显示
  protected onHide(): void {}                                 // 被其他视图遮盖
  protected onClose(): void {}                                // 关闭时调用

  // 便捷方法
  protected closeSelf(): void { UIManager.close(this.viewId); }
}
```

**生命周期流转：**
```
open(viewId, data)
├── 创建/复用节点
├── 添加到对应层级容器
├── onOpen(data)
│   ├── 同步 → 立即完成
│   └── 异步 → 等待 Promise resolve
├── 节点 active = true
└── 记录 ViewRecord

被高层级视图遮盖
└── onHide()

高层级视图关闭，恢复显示
└── onShow()

close(viewId)
├── onClose()
├── 注销事件订阅
├── 停止动画
├── 清理定时器
├── options.cache=true → 节点 active=false，移入缓存
├── options.cache=false → 销毁节点
└── 移除 ViewRecord
```

### 6.2 视图ID约定

- 使用 PascalCase 命名
- ID 与 Prefab 文件名对应
- ID 在配置表中集中定义，不在代码中硬编码字符串

## 7. 特殊UI处理

### 7.1 Loading 遮罩

- `showLoading(text?)` / `hideLoading()` 是便捷方法
- 内部通过 `open('LoadingMask', { text })` / `close('LoadingMask')` 实现
- Loading 层级最高（除 System），确保遮罩所有内容
- 支持进度文字更新

### 7.2 Toast 消息

- `showToast(text, duration?)` 便捷方法
- 默认 duration = 2000ms
- Toast 自动关闭，不需要手动 close
- 多个 Toast 排列显示，不互相覆盖

### 7.3 返回键处理（Android）

- Android 返回键优先关闭最上层 Dialog
- 如果没有 Dialog，则关闭最上层 FullScreen 页面
- 如果只有底层页面，触发退出确认弹窗
- 通过 `onBackKey()` 方法统一处理

## 8. 错误处理

| 场景 | 处理方式 |
|------|---------|
| 视图Prefab加载失败 | 记录 error 日志，open() 的 Promise reject |
| 同一 viewId 重复 open | 如果已打开，直接返回已有实例（不重复创建） |
| close 未打开的 viewId | 记录 debug 日志，不执行任何操作 |
| onOpen 中抛出异常 | 记录 error 日志，自动关闭该视图 |

## 9. 实现注意事项

1. **UI Prefab 由 AssetService 加载**，不允许每个页面自行维护加载逻辑
2. **重要 UI 状态由模型/服务提供**，避免页面之间直接互相改控件
3. **分辨率适配**：UIManager 在 onResize 中统一处理，各视图不需要自行处理
4. **安全区域**：SystemLayer 和 LoadingLayer 需要考虑刘海/安全区域
5. **事件清理**：BaseView 的 onClose 中应自动注销通过 EventBus 订阅的事件
