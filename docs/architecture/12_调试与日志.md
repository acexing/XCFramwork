## 1. Logger

### 1.1 模块职责

- `debug/info/warn/error` 分级日志
- 发布版可关闭高频日志，保留必要错误信息
- 日志中避免记录令牌、隐私数据和完整用户路径

### 1.2 接口定义

```typescript
export interface ILogger {
  debug(tag: string, message: string, ...args: unknown[]): void;
  info(tag: string, message: string, ...args: unknown[]): void;
  warn(tag: string, message: string, ...args: unknown[]): void;
  error(tag: string, message: string, ...args: unknown[]): void;
  setLevel(level: LogLevel): void;
  getLevel(): LogLevel;
  enableTag(tag: string): void;
  disableTag(tag: string): void;
}

export enum LogLevel {
  Debug = 0,
  Info = 1,
  Warn = 2,
  Error = 3,
  None = 4,
}
```

### 1.3 类结构设计

```
Logger
├── private level: LogLevel                    ← 当前日志级别
├── private enabledTags: Set<string> | null    ← 启用的 tag（null 表示全部启用）
├── private isDevMode: boolean                 ← 是否开发模式
│
├── debug(tag, message, ...args): void
├── info(tag, message, ...args): void
├── warn(tag, message, ...args): void
├── error(tag, message, ...args): void
├── setLevel(level): void
├── getLevel(): LogLevel
├── enableTag(tag): void
├── disableTag(tag): void
│
├── private shouldLog(tag, level): boolean
├── private formatMessage(tag, level, message, args): string
└── private output(level, formattedMessage): void
```

### 1.4 日志格式

```
[2026-10-10 14:30:00] [INFO] [SceneService] 切换到主场景
[2026-10-10 14:30:01] [WARN] [EventBus] 事件 CurrencyChanged 无订阅者
[2026-10-10 14:30:02] [ERROR] [SaveService] 存档读取失败: slot=progress, reason=checksum_mismatch
```

### 1.5 发布版行为

| 级别 | 开发版 | 发布版 |
|------|--------|--------|
| Debug | 输出到控制台 | 不输出 |
| Info | 输出到控制台 | 不输出 |
| Warn | 输出到控制台 | 输出到控制台 |
| Error | 输出到控制台 | 输出到控制台 + 错误上报 |

### 1.6 安全规则

- 日志中避免记录令牌、密钥、用户密码
- 不记录完整用户文件路径（使用相对路径或脱敏）
- 不记录用户隐私数据（如邮箱、手机号）

## 2. ErrorHandler

### 2.1 模块职责

- 捕获可恢复错误并提供友好提示
- 重要错误包含模块、操作、版本与上下文
- 不静默吞掉异常

### 2.2 接口定义

```typescript
export interface IErrorHandler {
  handle(error: Error, context?: ErrorContext): void;
  handlePromiseRejection(reason: unknown, context?: ErrorContext): void;
  registerHandler(handler: ErrorHandlerFn): void;
  setGlobalHandler(handler: GlobalErrorHandlerFn): void;
}

export interface ErrorContext {
  module: string;
  operation: string;
  version: string;
  extra?: Record<string, unknown>;
}

export type ErrorHandlerFn = (error: Error, context?: ErrorContext) => boolean;
export type GlobalErrorHandlerFn = (error: Error, context?: ErrorContext) => void;
```

### 2.3 类结构设计

```
ErrorHandler
├── private handlers: ErrorHandlerFn[]          ← 注册的错误处理函数
├── private globalHandler: GlobalErrorHandlerFn ← 全局错误处理函数
├── private logger: ILogger                     ← 日志引用
│
├── handle(error, context?): void
├── handlePromiseRejection(reason, context?): void
├── registerHandler(handler): void
├── setGlobalHandler(handler): void
│
├── private logError(error, context): void
├── private showErrorUI(error, context): void
└── private reportError(error, context): void   ← 发布版错误上报
```

### 2.4 错误处理流程

```
handle(error, context)
├── 1. logError(error, context)
│   └── 通过 Logger 输出 error 级别日志
│
├── 2. 遍历 handlers
│   ├── handler 返回 true → 错误已处理，停止
│   └── handler 返回 false → 继续下一个 handler
│
├── 3. 所有 handlers 都未处理 → globalHandler
│   ├── 开发版 → 显示错误弹窗（包含详细信息）
│   └── 发布版 → 显示友好提示 + reportError
│
└── 4. reportError（发布版）
    └── 上报到错误收集服务（如接入了）
```

### 2.5 全局异常捕获

- 监听 `window.onerror`（Web/开发版）
- 监听 `unhandledrejection` 事件
- Cocos 引擎的 `game.EVENT_ERROR` 事件
- 全局捕获的错误自动通过 ErrorHandler.handle 处理

## 3. DebugPanel

### 3.1 模块职责

- 当前场景、帧率、内存/资源统计
- 打开指定页面、增加测试货币、解锁测试内容
- 配置校验、资源路径检查、存档导入/重置
- 发布构建必须关闭或限制调试入口

### 3.2 接口定义

```typescript
export interface IDebugPanel {
  show(): void;
  hide(): void;
  toggle(): void;
  isVisible(): boolean;
  registerSection(name: string, section: DebugSection): void;
}

export interface DebugSection {
  name: string;
  render(container: Node): void;
}
```

### 3.3 类结构设计

```
DebugPanel
├── private panelNode: Node | null              ← 面板节点
├── private isVisible: boolean                  ← 是否可见
├── private sections: Map<string, DebugSection> ← 注册的面板分区
├── private fpsLabel: Label                     ← 帧率显示
├── private statsLabels: Map<string, Label>     ← 各项统计显示
│
├── show(): void
├── hide(): void
├── toggle(): void
├── isVisible(): boolean
├── registerSection(name, section): void
│
├── private createPanel(): Node
├── private updateStats(): void                 ← 定时更新统计
├── private onToggleKey(): void                 ← 快捷键监听
└── private destroyPanel(): void
```

### 3.4 内置面板分区

| 分区 | 内容 |
|------|------|
| Performance | 帧率、内存占用、DrawCall、资源数量 |
| Scene | 当前场景名、场景切换按钮 |
| Assets | 已加载 Bundle 列表、资源数量、加载耗时 |
| Events | 事件统计（监听数、触发次数） |
| Timers | 活跃定时器数量 |
| Pools | 对象池信息（池大小、活跃数） |
| Config | 配置校验结果、缺失字段列表 |
| Save | 存档信息、导入/重置按钮 |
| Localization | 缺失 key 列表 |
| Cheats | 增加货币、解锁物品、跳转关卡 |

### 3.5 快捷键

| 平台 | 快捷键 | 功能 |
|------|--------|------|
| Desktop | F1 | 切换 DebugPanel 显示 |
| Desktop | F2 | 显示/隐藏帧率 |
| Desktop | F3 | 强制 GC（如引擎支持） |
| Android | 三指点击 | 切换 DebugPanel 显示（开发版） |

### 3.6 发布版行为

- DebugPanel 代码在发布版中通过条件编译移除
- 或保留代码但隐藏入口，通过特殊操作才能激活
- 发布版绝不显示 Cheats 分区
- 发布版绝不显示存档重置按钮

## 4. PerformanceMonitor

### 4.1 模块职责

- 监控帧率、内存、DrawCall 等性能指标
- 性能低于阈值时自动记录日志
- 为 DebugPanel 提供性能数据

### 4.2 接口定义

```typescript
export interface IPerformanceMonitor {
  getFPS(): number;
  getMemoryUsage(): MemoryInfo | null;
  getDrawCallCount(): number;
  getStats(): PerformanceStats;
  startRecording(duration: number): void;
  stopRecording(): PerformanceReport;
}

export interface MemoryInfo {
  used: number;
  total: number;
}

export interface PerformanceStats {
  fps: number;
  fpsAvg: number;
  fpsMin: number;
  drawCalls: number;
  memory: MemoryInfo | null;
  assetCount: number;
}

export interface PerformanceReport {
  duration: number;
  statsHistory: PerformanceStats[];
  warnings: string[];
}
```

### 4.3 性能阈值告警

| 指标 | 阈值 | 告警级别 |
|------|------|---------|
| FPS | < 30 | warn |
| FPS | < 15 | error |
| DrawCall | > 200 | warn |
| 内存 | > 80% | warn |

- 告警通过 Logger 输出
- 连续 5 秒低于阈值才告警，避免瞬时波动误报

## 5. 实现注意事项

1. **发布构建必须关闭或限制调试入口**，DebugPanel 代码通过条件编译移除
2. **不要静默吞掉异常**，ErrorHandler 至少记录日志
3. **日志中避免记录令牌、隐私数据**，在 formatMessage 中过滤敏感字段
4. **开发版日志详细**，发布版只保留 warn 和 error
5. **DebugPanel 不影响游戏性能**，统计信息定时更新（每秒一次），不是每帧更新
