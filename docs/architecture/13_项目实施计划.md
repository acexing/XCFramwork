## 1. 阶段总览

| 阶段 | 名称 | 工作内容 | 产出 | 依赖 |
|------|------|---------|------|------|
| P0 | 工程基线 | 固定 Creator 版本、Git、代码规范、构建脚本 | 空工程可稳定构建 | 无 |
| P1 | 启动核心 | Bootstrap、日志、配置、场景服务 | Boot → Main 流程 | P0 |

| P3 | 资源与音频 | Bundle、AssetService、AudioManager | 资源按需加载与释放 | P1 |

| P6 | 工具与验收 | DebugPanel、性能监控、自动检查 | 可供新项目复制的模板仓库 | P1-P5 |

**建议先完成 P0-P4，再做一款小型垂直切片来验证架构。** 不要在核心玩法尚未验证时投入大量时间开发热更新、复杂网络层或通用编辑器工具。

### 3.3 编辑器操作步骤（P1-9 / P1-10）

场景文件包含编辑器生成的序列化信息（组件 CID 等），需在 Cocos Creator 中创建：

1. 用 Cocos Creator 3.8.8 打开 `XCFramwork/` 工程，等待资源导入完成
2. 在 `assets/scenes/` 下创建三个场景：`Boot.scene`、`Loading.scene`、`Main.scene`
3. 在 Boot 场景中：新建空节点 `GameBootstrap`，添加 `GameBootstrap` 脚本组件
4. 将 `Boot.scene` 设为启动场景（项目设置 → 通用 → 预览启动场景）
5. 点击预览运行，验证控制台输出：
   - `[PlatformService] 检测到平台: ...`
   - `[GameBootstrap] 开始初始化: ErrorHandler / GameConfig / PlatformService / SceneService`
   - `[GameBootstrap] 初始化完成，进入主场景`
   - `[SceneService] 切换到场景 Main`
6. 验证 P1-10：删除 `Main.scene` 模拟失败，确认 `[SceneService] 回退到安全场景 Boot` 日志出现

## 11. 风险清单

| 风险 | 处理建议 | 检查阶段 |
|------|---------|---------|
| Creator 小版本差异 | 固定版本；升级前在独立分支验证 | P0 |
| Steam 原生桥接兼容性 | 最早期做技术 Spike，验证打包、成就和云存档 | P5 |
| 图片内存过高 | 缩略图/原图分离、Bundle 分组、分页、按需释放 | P3 |
| 单例过多、耦合严重 | 服务接口明确，Bootstrap 统一组装 | P1 |
| 事件泄漏 | 生命周期绑定订阅；关闭页面时统一清理 | P2 |
| 存档损坏或迁移失败 | 版本号、备份/回退、迁移测试 | P4 |
| 插件许可证或停止维护 | 逐项审查，不把未验证插件作为核心依赖 | P5 |
| Android/PC 行为不一致 | 平台 Adapter + 双端真机/实机构建验收 | P5 |
| 渠道热更政策变化 | 接入前书面确认；热更模块可通过开关禁用，退化为全量发版 | P7 |
| 热更失败导致不可玩 | 首包保留最小可运行内容；自动回滚 + 版本冷却机制 | P7 |
| CDN 故障或劫持 | manifest 强制 HTTPS + 可选签名校验；多 CDN 源备选 | P7 |
