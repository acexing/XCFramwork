## 1. 模块职责

- 定义统一接口，业务层不直接调用平台 SDK
- 隔离 Steam / 桌面端与 Android 的输入、存档路径、支付/成就等差异
- 所有平台能力都提供"不可用"时的降级实现

## 2. 接口定义

```typescript
export interface IPlatformService {
  getPlatformName(): string;
  getCapabilities(): PlatformCapabilities;
  quitGame(): Promise<void>;
  openExternalUrl(url: string): Promise<void>;
  getStorageAdapter(): IStorageAdapter;
  vibrate(duration: number): Promise<void>;
  // Steam 专属
  unlockAchievement(achievementId: string): Promise<void>;
  setStat(statName: string, value: number): Promise<void>;
  getStat(statName: string): Promise<number>;
  isCloudSaveEnabled(): boolean;
  // Android 专属
  getBackKeyHandler(): (() => boolean) | null;
  shareContent(title: string, content: string): Promise<void>;
}

export interface PlatformCapabilities {
  cloudSave: boolean;
  achievements: boolean;
  overlay: boolean;
  haptics: boolean;
  externalLink: boolean;
  share: boolean;
  vibration: boolean;
}
```

## 5. 适配器实现

### 5.1 DesktopAdapter

```
DesktopAdapter
├── getPlatformName(): 'desktop'
├── getCapabilities(): { cloudSave: false, achievements: false, overlay: false, haptics: false, externalLink: true, share: false, vibration: false }
├── quitGame(): 退出应用
├── openExternalUrl(url): 使用系统默认浏览器打开
├── getStorageAdapter(): 返回基于文件系统的 StorageAdapter
├── vibrate(): 无操作（降级）
├── unlockAchievement(): 无操作（降级）
├── setStat/getStat(): 无操作（降级）
├── isCloudSaveEnabled(): false
├── getBackKeyHandler(): null
└── shareContent(): 无操作（降级）
```

### 5.2 SteamAdapter

```
SteamAdapter
├── getPlatformName(): 'steam'
├── getCapabilities(): { cloudSave: true, achievements: true, overlay: true, haptics: false, externalLink: true, share: false, vibration: false }
├── quitGame(): Steam 生命周期处理 + 退出应用
├── openExternalUrl(url): 通过 Steam Overlay 浏览器打开
├── getStorageAdapter(): 返回 Steam 云存档路径的 StorageAdapter
├── vibrate(): 无操作（降级）
├── unlockAchievement(id): 调用 Steamworks API
├── setStat/getStat(): 调用 Steamworks API
├── isCloudSaveEnabled(): 检查 Steam 云同步是否启用
├── getBackKeyHandler(): null
└── shareContent(): 无操作（降级）
```

**Steam 适配候选能力：**
- 初始化 Steamworks
- 成就、统计数据、云存档、Steam Overlay
- 退出游戏与 Steam 生命周期处理
- Steam SDK/第三方桥接的许可、二进制、架构与打包验证

### 5.3 AndroidAdapter

```
AndroidAdapter
├── getPlatformName(): 'android'
├── getCapabilities(): { cloudSave: false, achievements: false, overlay: false, haptics: true, externalLink: true, share: true, vibration: true }
├── quitGame(): 退出 Activity
├── openExternalUrl(url): 使用 Intent 打开浏览器
├── getStorageAdapter(): 返回 Android 文件系统的 StorageAdapter
├── vibrate(duration): 调用 Android Vibrator API
├── unlockAchievement(): 无操作（除非接入 Google Play Games）
├── setStat/getStat(): 无操作（除非接入 Google Play Games）
├── isCloudSaveEnabled(): false（除非接入 Google Play Games）
├── getBackKeyHandler(): 返回返回键处理函数
└── shareContent(title, content): 使用 Android Intent 分享
```

**Android 适配候选能力：**
- 返回键、应用暂停/恢复
- Android 文件访问与存档
- 震动、分享、渠道 SDK（如确实需要）
- Google Play Games 等服务（如确实需要）

## 6. 平台检测与适配器选择

```typescript
private detectPlatform(): PlatformType {
  if (sys.platform === sys.Platform.ANDROID) {
    return 'android';
  }
  if (sys.platform === sys.Platform.WIN32 || sys.platform === sys.Platform.MACOS) {
    // 检测是否为 Steam 版本（通过环境变量或 Steam API 初始化结果）
    if (this.isSteamVersion()) {
      return 'steam';
    }
    return 'desktop';
  }
  return 'desktop';
}
```

## 7. 降级策略

每个平台不支持的能力，适配器必须提供合理的降级实现：

| 能力 | 降级行为 |
|------|---------|
| cloudSave | 使用本地存档，不进行云同步 |
| achievements | 无操作，不报错 |
| overlay | 使用系统浏览器打开链接 |
| haptics | 无操作 |
| externalLink | 记录日志，不打开 |
| share | 复制到剪贴板（如支持） |
| vibration | 无操作 |

**关键原则：** 业务代码通过 `getCapabilities()` 检查能力是否可用，不直接假设能力存在。适配器方法即使能力不可用也不抛异常，而是静默降级。

## 8. 存储适配器

```typescript
export interface IStorageAdapter {
  read(key: string): Promise<string | null>;
  write(key: string, data: string): Promise<void>;
  delete(key: string): Promise<void>;
  exists(key: string): Promise<boolean>;
  listKeys(prefix: string): Promise<string[]>;
}
```

**各平台实现差异：**

| 平台 | 存储路径 | API |
|------|---------|-----|
| Desktop | 用户目录下游戏文件夹 | Cocos 文件系统 API |
| Steam | Steam 云存档目录 | Cocos 文件系统 API + Steam 云同步 |
| Android | 应用内部存储目录 | Cocos 文件系统 API |

- 存档目录通过平台 Adapter 提供，不硬编码安装目录为可写目录
- Steam 云存档需要明确文件路径、同步冲突策略与用户关闭云同步时的行为
- Android 测试卸载、升级安装、低存储空间和应用被系统回收后的恢复行为

---

## 9. 桌面端（非 Steam）的独立性

- `DesktopAdapter` 独立于 `SteamAdapter`
- 开发版使用 `DesktopAdapter`，不依赖 Steam SDK
- 发布版根据构建目标选择 `DesktopAdapter` 或 `SteamAdapter`
- 所有平台能力都应提供"不可用"时的降级实现

---

## 10. 实现注意事项

1. **业务代码通过接口调用**，不在业务代码里到处写平台判断
2. **Steamworks 应先做独立兼容性验证**，不要让其依赖污染通用核心
3. **Steam SDK/第三方桥接的许可、二进制、架构与打包验证**需在 P5 阶段早期完成
4. **Android 渠道 SDK 通过平台 Adapter 接入**，不直接在业务代码中调用
5. **所有适配器方法返回 Promise**，统一异步调用风格
