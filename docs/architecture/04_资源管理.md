## 1. 模块职责

- Bundle 加载、资源加载、预加载、缓存和释放
- 提供统一的加载进度与失败回调
- 统计资源引用/加载情况，开发版记录加载耗时
- 约定资源路径，避免业务代码拼接任意字符串

## 2. 接口定义

```typescript
export interface IAssetService {
  loadBundle(name: string): Promise<void>;
  loadPrefab(bundleName: string, path: string): Promise<Prefab>;
  loadSpriteFrame(bundleName: string, path: string): Promise<SpriteFrame>;
  loadAudioClip(bundleName: string, path: string): Promise<AudioClip>;
  loadJson(bundleName: string, path: string): Promise<JsonAsset>;
  preloadGroup(bundleName: string, paths: string[], onProgress?: (cur: number, total: number) => void): Promise<void>;
  releaseBundle(bundleName: string): void;
  releaseAsset(bundleName: string, path: string): void;
  isBundleLoaded(bundleName: string): boolean;
  getStats(): AssetStats;
}

export interface AssetStats {
  loadedBundles: string[];
  totalAssets: number;
  bundleDetails: Array<{
    name: string;
    assetCount: number;
    loadTime: number;  // 加载耗时(ms)，仅开发版
  }>;
}
```

## 4. Bundle 管理策略

### 4.1 Bundle 分类

| Bundle 名称 | 内容 | 加载时机 | 释放策略 |
|------------|------|---------|---------|
| core | 核心UI、通用弹窗、加载遮罩 | 启动时 | 常驻不释放 |
| ui_common | 通用UI组件、通用弹窗 | 启动时 | 常驻不释放 |
| gameplay_base | 基础玩法资源 | 进入Main场景前 | 场景切换时延迟释放 |
| chapter_01 | 第一章专属资源 | 进入第一章时 | 离开第一章时释放 |
| gallery | 图鉴系统资源 | 进入图鉴时 | 离开图鉴时释放 |

### 4.2 Bundle 加载流程

```
loadBundle(name)
├── 已加载 → 直接 resolve
├── 正在加载 → 返回已有的 Promise（防重复）
├── 未加载
│   ├── assetManager.loadBundle(name)
│   ├── 成功 → 存入 loadedBundles，记录统计
│   └── 失败 → reject，记录 error 日志
└── 返回 Promise
```

### 4.3 Bundle 释放流程

```
releaseBundle(name)
├── 未加载 → 记录 debug 日志，跳过
├── 已加载
│   ├── 检查 refCount，有引用中的资源 → 记录 warn 日志
│   ├── bundle.releaseAll()
│   ├── 从 loadedBundles 移除
│   ├── 从 assetCache 移除该 Bundle 的所有记录
│   ├── assetManager.removeBundle(name)（如引擎支持）
│   └── 更新统计信息
└── 完成
```

## 5. 资源加载流程

```
loadPrefab(bundleName, path)
├── ensureBundle(bundleName)
│   ├── Bundle 未加载 → loadBundle
│   └── Bundle 已加载 → 继续
├── 检查 assetCache
│   ├── 已缓存 → refCount++，返回缓存资源
│   └── 未缓存 → 继续
├── bundle.load(path)
│   ├── 成功 → 存入 cache，refCount=1，记录统计
│   └── 失败 → reject，记录 error 日志
└── 返回 Promise<Prefab>
```

## 6. 资源路径约定

### 6.1 路径规范

```typescript
// 正确：使用约定路径常量
const PREFAB_PATHS = {
  MainMenu: 'prefabs/ui/screens/MainMenu',
  SettingsDialog: 'prefabs/ui/dialogs/SettingsDialog',
  LoadingMask: 'prefabs/ui/common/LoadingMask',
} as const;

// 错误：业务代码拼接任意字符串
assetService.loadPrefab('ui_common', 'prefabs/ui/' + 'MainMenu'); // 禁止
```

### 6.2 路径常量集中管理

- 每个 Bundle 对应一个路径常量文件
- 路径常量在 `core/interfaces/` 下定义
- 业务代码只引用常量，不拼接字符串

## 7. 引用计数与释放

### 7.1 引用计数规则

- `load*` 方法调用时 refCount++
- `releaseAsset` 方法调用时 refCount--
- refCount 降为 0 时，从缓存移除并释放资源
- `releaseBundle` 时强制释放该 Bundle 所有资源（即使 refCount > 0）

### 7.2 与 UIManager 的配合

- UIManager 打开视图时通过 AssetService 加载 Prefab，refCount++
- UIManager 关闭视图（cache=false）时调用 releaseAsset，refCount--
- UIManager 关闭视图（cache=true）时保留节点但不释放 Prefab 资源

### 7.3 与 SceneService 的配合

- SceneService 切换场景时，afterLeave 钩子中释放离开场景的独占 Bundle
- 使用 `deferred` 策略：先加载新场景资源，再释放旧场景资源

## 8. 大量图片资源策略

对 3000 张以上的图片资源：

1. **建立唯一 `assetId`**，不把文件名直接当业务 ID
2. **生成元数据索引**：ID、Bundle、相对路径、缩略图路径、标签、解锁条件
3. **缩略图与原图分离**：图鉴列表加载缩略图，详情页加载高清图
4. **按章节/角色/主题拆分 Bundle**，避免启动时加载全量资源
5. **使用分页/虚拟列表**，避免一次创建几千个 UI 节点
6. **统一图片压缩、尺寸和格式**，分别评估 PC 与 Android 的纹理内存
7. **记录资源加载、失败和释放情况**，测试长时间浏览后的内存变化

## 9. 错误处理

| 场景 | 处理方式 |
|------|---------|
| Bundle 加载失败 | reject Promise，记录 error 日志 |
| 资源路径不存在 | reject Promise，记录 error 日志 |
| 重复加载同一资源 | 返回缓存实例，refCount++ |
| 释放未加载的 Bundle | 记录 debug 日志，跳过 |
| 释放有引用的资源 | 记录 warn 日志，仍执行释放 |

## 10. 实现注意事项

1. **遵循 Cocos 资源依赖与释放规则**，不要简单地在切场景后无差别 `releaseAll()`
2. **频繁使用的资源设置清晰的生命周期**，大型图片按需加载并在不再使用时释放
3. **不要把大量图片无差别塞进 `resources`** 并在启动时 `loadDir`
4. **开发版记录加载耗时**，发布版关闭统计以减少性能开销
5. **loadBundle 防重复**：同一 Bundle 并发加载只执行一次实际加载
