## 1. 模块职责

- 背景音乐、音效、环境音分组管理
- 主音量、音乐音量、音效音量设置
- 场景切换音乐策略、淡入淡出
- 防止按钮音效重复播放；可配置音效并发上限
- 读取/保存音频设置

## 2. 接口定义

```typescript
export interface IAudioManager {
  playMusic(bundleName: string, path: string, options?: MusicOptions): Promise<void>;
  stopMusic(fadeDuration?: number): void;
  pauseMusic(): void;
  resumeMusic(): void;

  playSfx(bundleName: string, path: string, options?: SfxOptions): Promise<void>;
  stopAllSfx(): void;

  setMasterVolume(volume: number): void;
  setMusicVolume(volume: number): void;
  setSfxVolume(volume: number): void;
  getMasterVolume(): number;
  getMusicVolume(): number;
  getSfxVolume(): number;

  isMusicPlaying(): boolean;
  getCurrentMusic(): string | null;
}

export interface MusicOptions {
  loop?: boolean;         // 是否循环，默认 true
  fadeIn?: number;        // 淡入时长(ms)，默认 0
  fadeOutPrevious?: number; // 上一首淡出时长(ms)，默认 0
}

export interface SfxOptions {
  volumeScale?: number;   // 音量缩放（0~1），默认 1
  loop?: boolean;         // 是否循环，默认 false
}
```

## 4. 音频分组设计

### 4.1 背景音乐（Music）

- 单一实例：同一时间只播放一首背景音乐
- 默认循环播放
- 支持淡入淡出切换
- 场景切换时可根据策略自动切换音乐

### 4.2 音效（Sfx）

- 多实例并发：使用 AudioSource 池支持多个音效同时播放
- 默认不循环
- 按钮音效防重复：同一音效在 100ms 内不重复触发
- 并发上限可配置（默认 8），超出时停止最早播放的音效

### 4.3 音量计算

```
实际音量 = masterVolume × groupVolume × options.volumeScale
```

- masterVolume 控制全局
- musicVolume / sfxVolume 分别控制各组
- options.volumeScale 用于单个音效的额外缩放

## 5. 场景切换音乐策略

| 策略 | 说明 | 适用场景 |
|------|------|---------|
| keep | 保持当前音乐不变 | 主菜单 → 设置弹窗 |
| stop | 停止当前音乐 | 主菜单 → 战斗场景（无音乐过渡） |
| change | 淡出当前音乐，淡入新音乐 | 主菜单 → 关卡场景 |

- 策略在场景配置中定义，SceneService 切换场景时通知 AudioManager
- 默认策略：`keep`

## 6. 音频设置持久化

```typescript
interface AudioSettings {
  masterVolume: number;
  musicVolume: number;
  sfxVolume: number;
  musicMuted: boolean;
  sfxMuted: boolean;
}
```

- 通过 SaveService 保存和读取
- 保存 key：`audio_settings`
- 启动时读取设置，应用到 AudioManager
- 音量变化时自动保存（防抖 500ms）

## 7. 资源加载与缓存

### 7.1 音乐资源

- 音乐文件较大，按需加载，不预加载全部
- 切换音乐时先加载新 AudioClip，加载完成后再淡入切换
- 旧 AudioClip 在淡出完成后释放

### 7.2 音效资源

- 常用音效（按钮点击等）可预加载到核心 Bundle
- 关卡专属音效在进入关卡时加载，离开时释放
- 音效 AudioClip 在播放完成后不立即释放（可能再次播放），由 Bundle 释放时统一清理

## 8. 错误处理

| 场景 | 处理方式 |
|------|---------|
| AudioClip 加载失败 | 记录 error 日志，playMusic/playSfx 的 Promise reject |
| AudioSource 组件不可用 | 记录 error 日志，音频功能降级（静默） |
| 音量值超出 0~1 | clamp 到 0~1 范围 |
| 同一音乐重复 playMusic | 忽略，记录 debug 日志 |

## 9. 实现注意事项

1. **引擎音频 API 外包一层 AudioManager**，不直接在业务代码中调用 AudioSource
2. **AudioSource 组件在场景中创建**：Music 用 1 个，Sfx 用池（默认 8 个）
3. **按钮音效防重复**：同一 path 的 Sfx 在 100ms 内只播放一次
4. **淡入淡出使用 tween**：修改 AudioSource.volume 属性实现
5. **Android 应用切后台时暂停音乐**：监听 `game.EVENT_HIDE` / `game.EVENT_SHOW`
